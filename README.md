# Dashboard-Xbox
Análise de 295 assinaturas do Xbox Game Pass em Excel (dados fictícios). Dashboard com filtro dinâmico e camada de cálculo separada da apresentação. Principais achados: o Ultimate concentra 70,6% da receita, 37,5% do faturamento bruto do Standard vira desconto e quase 70% da receita vem de add-ons, não da assinatura base.
